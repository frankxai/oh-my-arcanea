# Harness Engineering Review Checklist

## Agent Instructions
- [ ] Confirm agent capabilities and constraints
- [ ] Verify that agent instructions are clear and concise
- [ ] Ensure instructions cover all expected scenarios

## Tool Design
- [ ] Identify all tools involved in the process
- [ ] Assess usability and functionality of each tool
- [ ] Ensure tools are compatible with plugin architecture

## Context Delivery
- [ ] Verify the context passed to agents is accurate
- [ ] Ensure context is sufficient for decision-making
- [ ] Assess how context is updated during execution

## Planning Artifacts
- [ ] Review artifacts that guide plugin architecture decisions
- [ ] Confirm documentation is up-to-date
- [ ] Ensure all inferred dependencies are identified

## Permissions and Sandbox
- [ ] Assess permissions assigned to agents
- [ ] Validate sandboxing measures are effectively in place
- [ ] Ensure agents operate within defined limits

## Verification Loop
- [ ] Establish criteria for verification
- [ ] Verify outputs align with expectations
- [ ] Document any discrepancies and resolutions

## Component Removal Criteria
- [ ] Define criteria for removing unused components
- [ ] Review the impact of removal on system functionality
- [ ] Ensure proper documentation is in place before removal
