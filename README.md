# Oh My Arcanea
Oh My Arcanea is the Arcanea overlay for oh-my-opencode, adding Guardian routing, hooks, and swarm-ready coding workflows.
## What this repo is
- An Arcanea-flavored extension layer on top of oh-my-opencode
- A package for bringing Arcanea Guardian conventions into existing coding sessions
- A bridge between the Arcanea ecosystem and the wider oh-my-opencode workflow
## Install
`ash
npm install -g oh-my-arcanea
# or run without global install
npx oh-my-arcanea
`
## How this relates to Arcanea
Use Oh My Arcanea when you want the Arcanea coding overlay without moving your whole stack into Arcanea Code. It complements Arcanea Code and Arcanea Orchestrator rather than replacing them.
